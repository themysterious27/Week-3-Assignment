# Countdown Timer & JavaScript Tasks

Hi I'm **Prince Vats**

This project contains a **Countdown Timer web application** along with some **JavaScript practice tasks**.  
It is built using **HTML, CSS, and JavaScript** as part of my learning journey.



## Project Overview

### Countdown Timer

A simple and interactive timer application.

**Features:**
- Start, Pause, and Reset functionality  
- Displays time in minutes and seconds  
- Shows message when time is up  
- Clean and modern UI  



## JavaScript Tasks

### Task 1: Second Largest Number
- Finds the second largest number from an array  
- Uses loop and conditional logic  



### Task 2: Unique Elements from Arrays
- Combines two arrays  
- Returns only unique elements  



### Task 3: Student Analysis
- Calculates average marks of students  
- Finds the top-performing student  
- Works with objects and arrays
